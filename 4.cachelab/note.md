# 对 cache 的回顾

## cache 结构

cache类似于一个二维数组，有 $S = 2 ^ s$ 组，每组有 E 行，每行包括一个有效位 v , 标记位 tag , 以及 data (每个块大小为 $B = 2 ^ s$ )

想要找到对应的字体，cpu向内存发送的地址应由三部分(tag, s, b)组成

- [] 1. s，索引位，对应的组序号
- [] 2. tag，标记位，与组中的每一行进行匹配，判断是否命中
- [] 3. b，块偏移，表明需要多少字节

另外，cache里的有效位 (valit bit) 作用是判断该行是否为空。冷不命中表示改缓存块为空造成的不命中

## 替换策略

当 CPU 要处理的字不在组中任何一行，且组中没有一个空行，那就必须从里面选取一个非空行进行替换。选取哪个空行进行替换呢？书上给了我们两种策略：

- [] LFU，最不常使用策略。替换在过去某个窗口时间内引用次数最少的那一行
- [] LRU，最近最少使用策略。替换最后一次访问时间最久远的哪一行

本实验要求采取的策略为 LRU

# 对 Part B 的一点思考

32 x 32 的矩阵要求 misses < 300，64 x 64 的矩阵要求 m < 1300

以 32 x 32 的矩阵为例，先看看代码：

```
void trans_submit(int M, int N, int A[N][M], int B[M][N]) {
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            int tmp = A[i][j];
            B[j][i] = tmp;
        }
    }
}
```

对于 32 x 32 的矩阵，每行有 32 个 int，由于 cache 每行能存 32 个字节也就是 8 个 int，所以矩阵的每一行会占据 cache 的 4 行，当读入矩阵 A 的某一行的第一个元素时（比如A[0][0]），由于空间局部性原理，系统会把这个矩阵这一行的元素都读入 cache 里面，当写入 B（准确地说是写入B[0][0]） 时，由于是直接相连映射，B 的这一行的元素会把所有 A 的元素都驱逐出去并占领这 4 个 cache 行。在上述代码里，cpu 的执行顺序为读一个 A，就必须写一个 B，否则 tmp 就会被下一个元素覆盖掉

然后考虑 32 x 32 的矩阵，由于 cache 只有 32 个组也就是总共能存矩阵的 8 行，当写入第九行的 B[8][0] 时，它的地址又回到了 cache 的第 0 行，这就是容量未命中

于是我们考虑 8 x 8 的分块矩阵，此时 cache 的 32 个组恰好把 A 的 8 行和 B 的 8 行全部装下，但由于直接相连映射，A 和 B 对角线上的元素还是冲突的

可以结合题目给的这句话：You are allowed to define at most 12 local variables of type int per transpose function

于是我们可以考虑使用 8 个局部变量来存储 A，即使 B 的这一行元素把 A 都驱逐走，也不用去主存里找了。代码如下：

```
void transpose_submit(int M, int N, int A[N][M], int B[M][N])
{
    if (M == 32 && N == 32){
        int i, j, k;
        int t0, t1, t2, t3, t4, t5, t6, t7;

        // 将矩阵切割成 8 x 8 的块
        for (i = 0; i < N; i += 8){
            for (j = 0; j < M; j += 8){

                for (k = i; k < i + 8; k++){
                    t0 = A[k][j];
                    t1 = A[k][j + 1];
                    t2 = A[k][j + 2];
                    t3 = A[k][j + 3];
                    t4 = A[k][j + 4];
                    t5 = A[k][j + 5];
                    t6 = A[k][j + 6];
                    t7 = A[k][j + 7];

                    B[j][k] = t0;
                    B[j+1][k] = t1;
                    B[j+2][k] = t2;
                    B[j+3][k] = t3;
                    B[j+4][k] = t4;
                    B[j+5][k] = t5;
                    B[j+6][k] = t6;
                    B[j+7][k] = t7;
                }
            }
        }
    }

}
```
